# English Quest Bot — версия 1.6

Что умеет: регистрация по никнейму, персонаж (опыт, уровни 1–100 с привязкой к CEFR, монеты, серия дней с «заморозкой»), ежедневный квиз из вашей таблицы, профиль ученика, **памятки по темам**, **группы**, **домашние задания (тесты и авторские)**, **награды и штрафы от учителя**, **журнал всех ответов** и отчёты для учителя.

## Размещение на хостинге
Пошаговая инструкция для BotHost (репозиторий, настройки, переменные, проверка, обновления, резервные копии) лежит в файле **DEPLOY.md**.

## Запуск на компьютере (один раз настроить)

### 1. Создайте бота и получите токен
1. В Telegram найдите **@BotFather**, отправьте `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** — длинную строку. Никому её не показывайте.

### 2. Узнайте свой Telegram ID
Напишите боту **@userinfobot** — он ответит числом (Id). Это нужно, чтобы бот узнал в вас учителя.

### 3. Установите Python
- **Windows:** скачайте с python.org (версия 3.10 или новее). В установщике **обязательно поставьте галочку «Add python.exe to PATH»**.
- **Mac:** `brew install python` или установщик с python.org.

### 4. Подготовьте папку
Распакуйте архив, например, в `C:\english_quest_bot`. Скопируйте файл `settings.env.example` под именем **settings.env**, откройте его в Блокноте и заполните:
```
BOT_TOKEN=ваш_токен
TEACHER_IDS=ваш_id
```
Сохраните (Ctrl+S).

### 5. Установите библиотеки (один раз)
Откройте терминал в этой папке (Windows: в проводнике нажмите на адресную строку, напишите `cmd`, Enter) и выполните:
```
pip install -r requirements.txt
```

### 6. Запустите
```
python bot.py
```
Должно появиться «Из questions.xlsx загружено вопросов: 40, памяток: 5» и «Бот запущен». Бот работает, пока окно открыто и компьютер включён. Остановить: Ctrl+C.

## Как проверить
1. Откройте своего бота в Telegram, нажмите `/start` — вы войдёте как учитель.
2. Чтобы увидеть бота глазами ученика, зайдите с другого аккаунта (или попросите одного ученика) и пройдите регистрацию.
3. Нажмите «🎯 Квиз» и ответьте на вопросы.
4. С учительского аккаунта: `/students` — список учеников, `/student ник` — подробный отчёт по темам, навыкам и уровням.

## Как выглядит бот для ученика
- **Квиз — одна «карточка».** Вопросы сменяют друг друга в одном сообщении: ответил, увидел результат и пояснение, нажал «➡️ Дальше». В конце итог показывается в той же карточке. Текстовые ответы и нажатия кнопок меню бот убирает из чата, поэтому чат остаётся чистым.
- **Квиз обновляется каждое утро.** Новый «день» бота наступает в `DAY_START_HOUR` утра (по умолчанию 5:00, не в полночь: квиз, начатый вечером, не обнуляется в 00:00). Незаконченный квиз живёт до этого момента, можно вернуться кнопкой «🎯 Квиз» и продолжить. Утром старая карточка пропадает, а кнопка «Квиз» запускает новый. Все ответы, данные в незаконченном квизе, остаются в журнале и в статистике; в `/student` видно, сколько квизов начато и сколько закончено. Домашку это не затрагивает: её прогресс сохраняется, продолжать можно в «📝 Домашка».
- **Памятки и домашка** открываются и переключаются в одном сообщении (кнопки «К списку», «Закрыть»).
- **Никнейм:** 2–20 символов, буквы (русские и английские), цифры, `_` и `-`. Если ученик ввёл пробел, бот объяснит и предложит вариант с подчёркиванием одной кнопкой.
- Кнопка «/» в Telegram показывает меню команд (у учителя своё).

## Как выглядит бот для учителя
У учителя нет персонажа, уровней и квизов. Всё управление — **кнопками**, команды запоминать не нужно. Нижнее меню: «👥 Ученики», «🏷 Группы», «📝 Задания», «🎁 Награды», «📊 Сводка». Любой экран правится на месте (одно сообщение), а нажатие нижней кнопки посреди мастера просто отменяет его.

**Навигация**

- **👥 Ученики** → выбор: Все / Без группы / конкретная группа → список (по 8 на странице, ◀ ▶) → карточка ученика: 📈 Отчёт · 🏷 Группа (перевести одной кнопкой) · 🎁 Наградить · ⚠️ Штраф.
- **🏷 Группы** → список групп → карточка группы: 👥 Состав · 📈 Отчёт (слабые темы, кто пропал) · ➕ Добавить учеников (мультивыбор галочками: сначала без группы, потом из других групп) · 🎁 Наградить группу · 📝 Задание группе · 🎯 Уровень · ✏️ Название · 🗑 Удалить. Здесь же «➕ Создать группу» и «🆓 Ученики без группы».
- **📝 Задания** → ➕ Создать задание (мастер: тип → группа → название → тема и число вопросов или условие → срок) · 📥 На проверке (открывает сданную работу с кнопками «Принять / Доработать», даже если вы пропустили сообщение) · список заданий → кто выполнил · ⚙️ Ученики (отметить выполненным / сбросить попытку) · 📦 Закрыть.
- **🎁 Награды** → Ученику или Всей группе → награда или штраф → XP / монеты / заморозка → сумма кнопкой или «Другое число» → причина кнопкой, «Без причины» или своя. Опыт (XP) списать нельзя. Ученик получает уведомление с причиной.
- **📊 Сводка** → сколько учеников и групп, кто занимался сегодня, сколько заданий и работ на проверке, подсказки «первых шагов»; кнопки «⌨️ Команды» и «📚 Загрузка вопросов».

Ученик может состоять **только в одной группе**: при переводе в другую он автоматически уходит из прежней. Название группы может содержать пробелы и любые буквы; никнеймы и названия групп ищутся без учёта регистра (в том числе русские).

## Команды учителя (запасной способ)
Всё это есть и в кнопках, команды нужны для быстрых действий. Список виден по `/admin` и в «📊 Сводка» → «⌨️ Команды». Ник и название группы пишутся в любом регистре, в названии группы можно использовать пробелы.

| Команда | Что делает |
|---|---|
| `/addgroup название [A1..C1]` | создать группу |
| `/groups` | список групп с числом учеников |
| `/setgroup ник группа` | перевести ученика (`-` вместо группы убирает из группы) |
| `/delgroup название` | удалить пустую группу |
| `/students [группа]` | список учеников: уровень, серия, активность, точность за 7 дней |
| `/student ник` | отчёт по ученику: темы, навыки, уровни, какие памятки открывал |
| `/group название` | отчёт по группе: слабые темы за 14 дней, кто не заходил 5+ дней |
| `/reward ник тип число [причина]` | наградить; тип: `xp`, `coins`, `freeze` |
| `/penalty ник coins\|freeze число [причина]` | мягкий штраф: списать монеты или заморозку |
| `/rewardgroup группа тип число [причина]` | наградить всю группу |
| `/newhw` | создать домашнее задание (мастер с кнопками) |
| `/hw` | активные задания, кто сдал, закрыть задание |
| `/hwdone номер ник` | отметить выполненным (приняли вне бота) |
| `/hwreset номер ник` | сбросить попытку ученика |

Ученик получает уведомление о награде или штрафе с причиной. Опыт (XP) списывать нельзя: уровень не должен падать. Все награды и штрафы сохраняются в базе с причиной и датой.

## Домашние задания
Два типа, оба создаются командой `/newhw` пошагово кнопками (тип, группа или «все ученики», название, тема и число вопросов либо условие, дедлайн):

- **Тест из банка.** Бот берёт нужное число вопросов выбранной темы и фиксирует их, чтобы у всех был один набор. Ученик проходит тест в боте, получает результат сразу, одна попытка. Если бот перезапустили или ученик ушёл посередине, он продолжит с того же места. Награда: XP и монеты за ответы плюс бонус +10 XP за выполнение в срок. После дедлайна задание всё равно можно выполнить, но XP меньше и без бонуса.
- **Авторское задание.** Вы пишете условие (что сделать и как сдать). Ученик нажимает «Сдать работу» и присылает текст, голосовое, фото или файл. Вам приходит работа с кнопками «✅ Принять» (ученик получает +20 XP и +5 монет) и «🔁 Доработать» (можно сразу написать комментарий). Ученик получает уведомление о каждом решении.

Что видит ученик: кнопка «📝 Домашка» со списком заданий и статусами (🆕 новое, ▶️ в процессе, 📤 на проверке, 🔁 доработать, ✅ выполнено, ⚠️ просрочено).

Что видите вы: `/hw` (или кнопка «📝 Домашка») показывает активные задания и сколько человек выполнили. Нажмите на задание, чтобы увидеть статус каждого ученика (для тестов с баллами) и закрыть задание. Если работу приняли вне бота, отметьте так: `/hwdone номер ник`. Чтобы дать ученику пройти тест заново: `/hwreset номер ник`.

Все ответы в тестах-домашках попадают в тот же журнал, что и квизы, поэтому `/student` и `/group` учитывают их в аналитике по темам.

## Памятки
Лежат на листе `cheatsheets` в `questions.xlsx` (колонки `topic`, `cefr`, `text`). Название темы должно точно совпадать с темой в листе `questions`. Слова в **двойных звёздочках** бот покажет жирным. Ученик открывает памятки кнопкой «📖 Памятки», а после неверного ответа получает кнопку «📖 Памятка по теме». Открытия памяток записываются в журнал, их видно в `/student`.

## Обновление вопросов и памяток
- **Без перезапуска:** отправьте боту файл `.xlsx` (с учительского аккаунта). Бот загрузит вопросы и памятки и сообщит, какие строки пропущены и почему. Вопросы с тем же `id` обновляются, новые добавляются.
- Чтобы убрать вопрос, поставьте в колонке `active` значение 0 (строку не удаляйте).
- При каждом запуске бот также читает файл `questions.xlsx` из папки.

## Файлы
- `bot.py` — сам бот (команды, квиз, профиль, команды учителя)
- `db.py` — база данных и игровая логика (XP, уровни, серия, импорт)
- `settings.env` — токен, ваш ID, настройки
- `questions.xlsx` — банк вопросов
- `bot.db` — **появится после первого запуска** (на хостинге лежит в `/app/data`): все данные учеников и журнал ответов. Это самый ценный файл: делайте его копии. При переезде на сервер его просто переносят вместе с папкой.

## Как обновиться с версии 1.5
1. Остановите бота (Ctrl+C).
2. Замените в папке файлы `bot.py` и `db.py`. Файлы `bot.db` и `settings.env` не трогайте: данные сохранятся.
3. Запустите `python bot.py`.
4. Нажмите `/start` со своего учительского аккаунта: появится новое нижнее меню. Ученикам ничего делать не нужно. Данные и настройки сохранятся, база обновится сама.
5. Настройка `DAY_START_HOUR` работает и без правок `settings.env` (по умолчанию 5). Чтобы изменить час, добавьте в свой `settings.env` строку `DAY_START_HOUR=число`.
6. Таблицу с вопросами менять не нужно.

## Резервная копия
«📊 Сводка» → «💾 Резервная копия базы» (или `/backup`): бот присылает файл базы. Делайте копию раз в неделю и перед обновлением.

## Что можно настроить
В `settings.env`: `DAY_START_HOUR` (час, с которого начинается новый день; `0` = полночь). В начале `db.py`: `BASE_XP` (скорость роста уровней), `XP` (сколько XP за верный/неверный ответ в daily и practice), `MAX_FREEZES`. В `settings.env`: `QUIZ_SIZE` (вопросов в квизе).

## Правила игры сейчас
- Первый квиз за день: +10 XP за верный ответ, +2 за неверный, +1 монета за верный. Он же продлевает серию.
- Повторные квизы в тот же день: тренировка, +3/+1 XP, без монет. Все ответы всё равно пишутся в журнал.
- Пропуск одного дня спасает «заморозка» (одна даётся сразу, ещё одна за каждые 7 дней подряд, максимум 2).
- Вопросы подбираются из уровня ученика и следующего, сначала те, что он давно не видел.
- Если ученик посреди квиза нажмёт «Профиль» или «Памятки», квиз не сбрасывается. Повторное нажатие «Квиз» в тот же день вернёт к текущему вопросу.
